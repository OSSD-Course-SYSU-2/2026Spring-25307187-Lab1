# 2048 休闲益智小游戏
## 基于鸿蒙 ArkTS 开发 · 按键交互版数字合成游戏

---

## 📌 项目简介
本项目基于**DevEco Studio**开发环境，采用鸿蒙原生ArkTS语言完成2048经典益智游戏开发。
通过界面固定方向按键控制方块上下左右滑动移动，实现数字合并、随机生成、分数统计、游戏结束判定完整核心逻辑，界面简洁流畅，交互稳定，适配鸿蒙应用开发标准规范。

## ✨ 核心功能特点
- 自定义**上下左右四方向功能按键**，点击即可控制方块移动
- 遵循原版2048游戏规则，相同数字触碰自动合并累加
- 每次移动后随机空白位置自动生成新数字方块
- 实时计算并展示游戏当前得分数据
- 自动判定棋盘填满无法移动，触发游戏结束提示
- 界面布局规整，方块样式清晰，操作手感流畅
- 代码模块化编写，结构清晰，可读性与扩展性强

## 🎮 游戏操作说明
1. 程序运行自动初始化4×4游戏棋盘
2. 点击界面**上、下、左、右**四个功能按钮
3. 方块跟随按键方向整体滑动，相邻相同数字自动合成
4. 不断合成更大数字，直至合成2048即为游戏胜利
5. 棋盘无空位且无法合并时，游戏自动结束
